# ARNITA

## What it is

A small coding agent.

## Purpose

- Learning a little bit of the technology behind LLMs

## Notes
- Explicitly overengineered to learn and practice C# skills that I seemed to have lost in 2025 due to complete overdependence on AI.
- Mostly hand coded. See Disclosure section for more on LLM usage.
- Initially I was building an "LLM Proxy" but within few days it was clear that it was more than I could chew at that point.
- Decided to build a small CLI coding agent in C#.
- Crush and Aider are primary inspirations.

## Feature List

- Currently it is just a dumb 1-1 request response chat interface on the command line.
- Note: LLM suggested a bunch of features as a good progression. But I cannot verify if they are good or needed, so I skipped them here. As things become clear, I will list them here.

## LLM usage disclosure
